# Import pipeline

How Godot imports source assets: what to commit, texture, 3D scene, animation, audio and font import options, resource formats, and loading at runtime. Written for Godot 4.x, checked against 4.7.

Art direction and asset specs go to `game-assets`; export-time compression and platform formats to `godot-export`.

Contents: What to commit; Textures; 3D scenes; Animations; Audio; Fonts; Resource formats; Loading at runtime; Pitfalls.

## What to commit

```
textures/player.png          # source: commit
textures/player.png.import   # import settings: commit
scripts/player.gd
scripts/player.gd.uid        # 4.4+ UID sidecar: commit, move and rename with its file
.godot/                      # import cache, editor state: ignore
```

- Never edit `.godot/imported/`; it is regenerated from the sources and the `.import` files.
- 4.4+: scripts, shaders and other non-imported resources get a `.uid` sidecar holding their `uid://`. Imported assets keep their UID inside the `.import` file. Commit both, and move or rename the sidecar together with its file (the editor's FileSystem dock does this; a shell `mv` doesn't). See `references/tscn-tres-format.md`.
- Godot 3's `.import/` folder no longer exists. Strip it from old `.gitignore` files.
- Change settings in the Import dock, then Reimport. Settings for many files at once: select them all, or set defaults in Project Settings > Import Defaults.

## Textures

| Compress mode | Quality | VRAM | Use for |
|---|---|---|---|
| Lossless (**default**) | exact | high | 2D sprites, pixel art, UI |
| Lossy | reduced | high | Large 2D backgrounds where disk size matters |
| VRAM Compressed | reduced | low | 3D textures, large textures on mobile |
| VRAM Uncompressed | exact | high | Where compression artefacts are unacceptable |
| Basis Universal | reduced | low | 3D, smallest on disk |

- Detect 3D is on by default: when a texture is first used in a 3D material, Godot enables mipmaps and switches it to VRAM Compressed (or what `detect_3d/compress_to` says), then reimports. For pixel art used in 3D, set Compress To or switch back to Lossless afterwards; don't disable Detect 3D, which keeps mipmaps.
- VRAM compression is for 3D. Don't use it for 2D elements.
- High Quality (BPTC/ASTC) is Forward+ and Mobile only; the default is S3TC on desktop and ETC2 on mobile and web.
- Mipmaps: on for 3D and for 2D that zooms out; off for UI.
- Filter and repeat are **not** import options in Godot 4. Set them on the CanvasItem (`texture_filter`, `texture_repeat`), project-wide (Rendering > Textures > Canvas Textures > Default Texture Filter = Nearest for pixel art), or as sampler hints in materials and shaders. Godot 3's "Flags > Filter/Repeat" are gone.
- `process/fix_alpha_border` (default on) prevents dark halos on transparent sprite edges.
- Normal maps: set `compress/normal_map` or let detection mark them; a normal map imported as colour looks wrong.

## 3D scenes

Prefer glTF 2.0 (`.glb` for one file, `.gltf` + textures for diffable output). `.blend` imports directly when Blender is configured in the editor settings. FBX imports through ufbx. OBJ is static meshes only.

Name suffixes in the source file (case-insensitive; `-`, `$` or `_` as separator) set node types on import:

| Suffix | Result |
|---|---|
| `-noimp` | Node or animation is skipped |
| `-col` / `-convcol` | Mesh kept, plus a StaticBody3D with a trimesh / convex shape |
| `-colonly` / `-convcolonly` | Mesh replaced by the StaticBody3D and shape |
| `-occ` / `-occonly` | Adds an occluder from the mesh / converts the mesh to an occluder |
| `-navmesh` | NavigationRegion3D from the mesh |
| `-rigid` | RigidBody3D |
| `-vehicle` / `-wheel` | VehicleBody3D / VehicleWheel3D |
| `loop` / `cycle` | Animation clip whose name starts or ends with it imports looping (no hyphen needed) |

Turn off `nodes/use_node_type_suffixes` to keep source types (`-noimp` and `-loop` still apply), or `nodes/use_name_suffixes` to ignore suffixes entirely.

- Advanced Import Settings (double-click the file): per-node, per-mesh and per-material options, collision generation, extracting materials to `.tres` so they survive reimport, and LOD (generated by default).
- 4.7+: the import type can be a single `Mesh` or a `MeshLibrary` (for GridMap) instead of a scene.
- Don't edit the imported scene's nodes directly. Create an inherited scene or instance it in a wrapper scene, or use an import script (`EditorScenePostImport`).
- Runtime glTF loading (mods, user content): `GLTFDocument.append_from_file(path, state, flags)` then `generate_scene(state)`. 4.7+: the flags are the `GLTFDocument.ImportFlags` bitfield, and `EditorSceneFormatImporter`'s import constants moved into an `ImportFlags` enum (GDScript code keeps working; C# must use the enum).

## Animations

- Split one long take into clips in Advanced Import Settings > Animations with start and end frames and a loop mode per clip.
- Retargeting (4.0+): set a `BoneMap` with a `SkeletonProfileHumanoid` on the Skeleton3D in Advanced Import Settings, then share an `AnimationLibrary` between characters.
- Save animations to external `.res` files there if you edit them in Godot, or reimport overwrites the edits.

## Audio

| Format | Use for | Key options |
|---|---|---|
| WAV | Short SFX (no decode cost) | loop mode, `force/mono` |
| Ogg Vorbis | Music, long ambience | `loop`, `loop_offset`, `bpm`, `beat_count` |
| MP3 | Music when that's what you have | same as Ogg |

Force Mono for sounds played by `AudioStreamPlayer3D`; stereo doesn't spatialise. Playback and buses are in `references/audio.md`.

## Fonts

- 4.7+: the dynamic font importer's `hinting` default is 3 ("Light (except pixel fonts)") instead of 1 ("Light"). Fonts imported before keep `hinting=1` in their `.import`; new or regenerated imports change. Set it back to 1 to match 4.6.
- Pixel fonts: disable antialiasing and use a size multiple of the design size, or import a bitmap font.

## Resource formats

| Ext | Kind | Use for |
|---|---|---|
| `.tscn` / `.tres` | text | Scenes and resources you diff and review |
| `.scn` / `.res` | binary | Large generated data (baked meshes, big animation sets) that nobody reads |

`ResourceSaver.save(res, "res://data/item.tres")` picks the format from the extension. Exports convert text resources to binary anyway, so text costs nothing at runtime. Never load `.tres`/`.res` from user-writable places: loading a resource can run embedded scripts (see `references/save-and-config.md`).

## Loading at runtime

- `preload()` for fixed paths (resolved at parse time); `load()` for data-driven paths.
- In exported builds, assets become `*.import`/`*.remap` entries, so `DirAccess` scans for `*.png` or `*.tres` fail. Use `ResourceLoader.list_directory()` (4.4+) or an exported array of resources.
- Loading screens: `ResourceLoader.load_threaded_request(path)`, poll `load_threaded_get_status(path, progress)` each frame, then `load_threaded_get(path)` once it reports `THREAD_LOAD_LOADED`. Details are in `references/threading.md`.

## Pitfalls

| Symptom | Cause | Fix |
|---|---|---|
| Blurry pixel art | Linear filter | Default Texture Filter = Nearest, or `texture_filter` on the node |
| Pixel art turned smeary after use in 3D | Detect 3D switched it to VRAM Compressed | Set it back to Lossless or change Compress To |
| Dark outlines on sprites | Alpha bleed | Fix Alpha Border on |
| Imported model has no collision | No suffix, no generated shape | Add `-col`/`-colonly` or enable physics in Advanced Import Settings |
| Material edits lost on reimport | Edited the embedded material | Extract materials to files |
| Settings lost after clone | `.import` not committed | Commit `.import`; ignore only `.godot/` |
| "Unrecognized UID" after a move | `.uid` sidecar left behind | Move the sidecar with the file or let the editor move both |
| High VRAM on mobile | Large Lossless textures | VRAM Compressed for big 3D or background textures |
