# 2D: tiles, draw order, parallax, lights

TileMapLayer and TileSet, canvas layers and draw order, coordinate conversion, Parallax2D, 2D lights, pixel snapping and antialiasing. Written for Godot 4.x, checked against 4.7.

Character movement on tiles goes to `godot-physics`; 2D shaders and particles to `godot-shaders`; procedural map algorithms to `level-design`; tile art specs to `game-assets`.

Contents: TileMapLayer; Draw order and canvas layers; Coordinate conversion; Parallax2D; 2D lights and shadows; Pixel art, snapping, antialiasing.

## TileMapLayer

- 4.3+: `TileMapLayer` replaces the deprecated `TileMap`. One node holds one layer; stack several (background, walls, foreground) under a `Node2D`. Calls lose the leading `layer` argument: `set_cell(coords, source_id, atlas_coords, alternative_tile)`.
- Migrating: select the old `TileMap` and use its toolbar's "Extract TileMap layers as individual TileMapLayer nodes", then fix scripts that passed a layer index.
- Save the `TileSet` as an external `.tres` so every layer and level shares it. Set Tile Size before adding atlases, and turn on the atlas's Use Texture Padding to stop bleeding.
- Sources: an atlas source (texture sliced into a grid, addressed by `atlas_coords`) or a scene collection source (whole scenes as tiles, each instanced separately: use for doors and chests, not terrain).
- Per-tile data layers live on the TileSet: physics (collision polygons), navigation, occlusion, and custom data (named, typed values such as `damage: int` or `is_ladder: bool`).
- Node toggles: `collision_enabled`, `navigation_enabled` on the layer.

```gdscript
extends TileMapLayer

func cell_damage(global_pos: Vector2) -> int:
	var cell := local_to_map(to_local(global_pos))  # local coords, not global
	var data := get_cell_tile_data(cell)            # null on empty cells
	return data.get_custom_data("damage") if data else 0

func dig(cell: Vector2i) -> void:
	erase_cell(cell)  # same as set_cell(cell, -1)
```

Other calls: `map_to_local(cell)` (cell centre), `get_used_cells()`, `get_surrounding_cells(cell)`, `get_neighbor_cell(cell, TileSet.CELL_NEIGHBOR_RIGHT_SIDE)`, `clear()`.

### Terrains (autotiling)

1. TileSet > Terrain Sets: add a set and pick the mode (Match Corners and Sides, Match Corners, Match Sides).
2. Add terrains to the set, then paint peering bits on each tile.
3. Paint with Connect (joins neighbours) or Path (joins along the stroke only).

```gdscript
set_cells_terrain_connect(cells, terrain_set, terrain, true)  # ignore_empty_terrains
set_cells_terrain_path(path_cells, terrain_set, terrain, true)
```

Missing peering combinations give odd tiles. Fill the set before blaming the code.

### Runtime and performance

- Edits are applied at the end of the frame. Call `update_internals()` only when you must read the result immediately; it is expensive in loops.
- Per-cell overrides: implement `_use_tile_data_runtime_update(coords)` and `_tile_data_runtime_update(coords, tile_data)`, then call `notify_runtime_tile_data_update()` when the set of overridden cells changes. Keep it to a few cells; `TileData` sub-resources are shared with the TileSet, so duplicate before editing them.
- `rendering_quadrant_size` (default 16) batches drawing. It does not apply to a Y-sorted layer.
- 4.5+: `physics_quadrant_size` (default 16) merges the collision shapes of similar tiles in each quadrant into composite colliders. This removes most "snagging on tile seams". Larger values are more reliable and slower to update when cells change. `get_coords_for_body_rid()` gets less precise; set the size to 1 to get exact cells back.
- Before 4.5, fix seam bumps with merged `StaticBody2D` polygons or `floor_snap_length` on the body (see `godot-physics`).
- Y-sort: enable `y_sort_enabled` on the layer and set the per-tile `y_sort_origin`.

### Generation names

For generated maps, give each generator its own `RandomNumberGenerator` with a fixed `seed` (not the global `randf()`), and use `FastNoiseLite` (`noise_type`, `frequency`, `fractal_octaves`, `get_noise_2d(x, y)`) for terrain values. Write tiles with `set_cell` or the terrain calls above. Algorithms (cellular automata, BSP, WFC) are in `level-design`.

## Draw order and canvas layers

- In one canvas layer, later siblings draw on top. `z_index` overrides that without reordering; `z_as_relative` (default true) adds the parent's z.
- `CanvasLayer` gives an independent layer with its own transform, unaffected by `Camera2D`. Higher `layer` draws on top. Typical: parallax at -1, world at 0, HUD at 1, pause and transitions at 10+.
- Use z_index or tree order for world objects. Use CanvasLayer only for things that must ignore the camera.
- `Camera2D` works by setting the viewport's `canvas_transform`.

## Parallax2D

- 4.3+: `Parallax2D` replaces `ParallaxBackground` + `ParallaxLayer`. Use one node per depth band.
- `scroll_scale`: 0 static, below 1 farther, 1 moves with the camera, above 1 foreground.
- Infinite repeat: put the texture's top-left at (0, 0) (not centred), set `repeat_size` to the texture size, and raise `repeat_times` if the camera zooms out.
- Split screen: clone the parallax nodes into each SubViewport. Give each set a parent with its own `visibility_layer` and set each SubViewport's `canvas_cull_mask` to show only its set (see `references/camera.md`).

## 2D lights and shadows

| Node | Role |
|---|---|
| `CanvasModulate` | Darkens the whole canvas (ambient colour) |
| `PointLight2D` | Textured point or spot light; size comes from the texture and `texture_scale` |
| `DirectionalLight2D` | Sun or moon |
| `LightOccluder2D` | Casts shadows; generate one from a Sprite2D's menu |

- Turn on `shadow_enabled` on the light. Use `shadow_filter` None for pixel art and PCF5 or PCF13 for soft shadows.
- Masks: the light's `range_item_cull_mask` picks lit items, its `shadow_item_cull_mask` picks occluders, and the occluder's `occluder_light_mask` picks lights.
- The clear colour is never lit. Use a full-screen Sprite2D or ColorRect as the background.
- Normal-mapped sprites: use a `CanvasTexture` with diffuse, normal and optional specular textures, and set the light's `height`.
- Additive sprites (`CanvasItemMaterial` blend Add) make cheap fake lights with no shadows.

## Pixel art, snapping, antialiasing

- Project Settings: Rendering > Textures > Canvas Textures > Default Texture Filter = Nearest. Per node: `texture_filter`.
- Rendering > 2D > Snap: Snap 2D Transforms to Pixel, Snap 2D Vertices to Pixel. GUI: Snap Controls to Pixels.
- Stretch and integer scaling are in `references/ui-control.md`.
- MSAA 2D (Rendering > Anti Aliasing > Quality > MSAA 2D) works only in Forward+ and Mobile. It smooths geometry edges, not texture content, fonts or shader output. Keep it off for pixel art.
- Prefer per-call antialiasing: `draw_line(a, b, color, width, true)`, `Line2D.antialiased`.
- 4.7+: antialiased line drawing no longer adds the feather, so such lines render thinner after an upgrade. Raise `width` to match the old look.
- Custom drawing: override `_draw()` and call `queue_redraw()` when state changes; never call `_draw()` directly.
- Large sprites with big transparent areas: Sprite2D menu > Convert to MeshInstance2D to cut fill rate on weak GPUs.
- 4.7+: `DrawableTexture2D` is experimental; don't build on it yet.
