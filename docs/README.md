# docs

- `3rd-party/` — one folder per repo checked out under `3rd-party/` (gitignored): a hand-written overview and a generated catalog of every plugin, skill, agent, command and hooks file. Start at [3rd-party/README.md](3rd-party/README.md). Regenerate catalogs with `scripts/catalog-3rd-party.py`.
- `plans/` — current plans. [plans/plugin-adoption.md](plans/plugin-adoption.md) decides what comes into the restarted marketplace from the archive and third-party repos.
- `research/` — research notes. `research/inventory-2026-10-17/` holds the per-scope inventories behind the adoption plan. [research/claude-hud.md](research/claude-hud.md) compares claude-hud with the archived mods. [research/uiux-design.md](research/uiux-design.md) designs the UI/UX collection. [research/tools-to-research.md](research/tools-to-research.md) grades the repos listed in [Tools to research.md](Tools%20to%20research.md) as helpful, worthless or investigate more.
- `Tools to research.md` — the running inbox of links to look at. Move an entry's verdict into `research/` once it has been researched.

Older plans, plugin pages and research from before the marketplace restart live under `archive/docs/`.
