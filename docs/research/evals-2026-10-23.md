# Eval run, 2026-10-23: paperthin ports

These are the trigger evals for the five model-invoked plugins ported from LilMGenius/paperthin (`docs/plans/paperthin-ports.md`, S6).

Each suite ran with `claude plugin eval plugins/<p> --trust-plugin -j 3`, once per case. The default with/without ablation applied, so every case also ran in a no-plugin baseline arm. The model was set in each case's frontmatter (`claude-sonnet-5-5`).

| catchup | 2 positive, 2 hard negative | 4/4 | |

Every positive fired with the plugin and scored 0 in the baseline arm (Δ +1.00). Every hard negative stayed quiet in both arms. The hard negatives were aimed at doubt-review, docs-audit, handoff, necromancy, the-fool, debloat and code dedupe.

There was one run per case, so this rules out gross mis-routing but says nothing about variance. Re-run with `--runs 3` if a description changes.
