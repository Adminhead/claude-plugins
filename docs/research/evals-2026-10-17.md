# Eval run, 2026-10-17

`claude plugin eval` over every plugin with an `evals/` folder (53 plugins, 91 cases), one run per case, with the no-plugin baseline arm (`--ablation with-without`), Claude Code 2.1.302. Reports stayed local (`--no-publish`); per-plugin results are in each plugin's gitignored `evals/results/`.

Cost: $10.31 for the first pass plus $6.50 for the rerun.

## Results

- First pass: 79 cases loaded and 74 passed with the plugin. 12 cases in `deprecation-migration`, `doubt-review` and `ui-direction` failed to load: their `prompt.md` frontmatter had an unquoted `: ` in `description`. Fixed by quoting; every eval frontmatter now parses as YAML.
- Rerun of those 12 plus the 5 failures, with scaffolds and tool grants where the case needs them: all passed except one outcome case.
  - `terraform-routing` had not fired once; after naming pasted plan output in the description it fired 3 of 3 (0 of 3 without the plugin).
  - `dependabot-sweep-merge-rules`, `stance-react-measure-first`, `profile-changes-output` and `testing-observable-behaviour` passed once run with `--scaffold` and the tools they need (`--allow-tools Bash`, `Write`, `Edit`).
  - `ui-direction` outcome cases: 5 of 6 scored 1.0 with the plugin against 0.4 without. `outcome-conference-format` scored 0.4 in both arms; the judge flags long pages as noisy.
- Trigger graders: with the plugin, every routing and trigger case fired the intended skill; negative cases stayed quiet.

## Running them

Cases that need a scaffold or gated tools pass only with those flags:

```
claude plugin eval plugins/<name> --trust-plugin --runs 1 -j 4 --no-publish [--scaffold] [--allow-tools Bash Write Edit]
```

Read a case's `scaffold.sh` before passing `--scaffold`: it runs as you.
