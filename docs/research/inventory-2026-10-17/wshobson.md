# wshobson/agents inventory (re-judged for the new marketplace structure)

Source: `3rd-party/wshobson-agents` (marketplace name **`claude-code-workflows`**), MIT (Seth Hobson; a few plugins credit other authors, all MIT). Actively maintained: last commit 2026-10-15, 111 commits since July. 92 local plugins: 185 skills, 202 agents, 105 commands, 2 hooks.json. Prior review rows in `archive/docs/research/third-party-skills-review.md` are reused where noted ("prior").

## Summary

- Verdicts (rows below): **cross-dep 2, port 10, merge 24, skip 16 rows** plus bulk skips covering about 140 skills, all 202 agents and all 105 commands.
- **Cross-dep viability is poor for the stacks we target.** Every language, IaC, testing, security, database and API plugin bundles skills with persona agents (154 of 202 say "Use PROACTIVELY", mostly `model: opus`) and slash commands, so installing one would add unwanted auto-delegating agents. Only two upstream plugins are both single-component and good: `avoid-ai-writing` (1 skill) and `file-conversion` (1 skill). Both need `claude-code-workflows` added to `allowCrossMarketplaceDependenciesOn`.
- Smallest stack-relevant plugins and why they still fail as deps: `database-design` (1 skill + 2 agents), `shell-scripting` (3 skills + 2 agents), `kubernetes-operations` (4 skills + 1 agent, has stale PodSecurityPolicy/kubeval content), `skill-forge-essentials` (3 skills), `documentation-standards` (2 niche skills). Port the good pieces instead.
- Most "Master X" language skills (python-*, go-concurrency, rust-async, nodejs-backend, sql-optimization) are generic tutorials Claude already knows. A few are worth mining as references, and some are stale (`@v4` action tags, `pg_stat_statements.total_time`, PodSecurityPolicy).
- Headline picks: cross-dep `avoid-ai-writing` and `file-conversion`; port a real hook from the `block-no-verify` idea (zero context cost, baseline); port `python-patterns` (anti-patterns spine) and `uv` for python-meta; port `kubernetes`, `helm`, `gitops` for iac-meta (prior plan); port `bash` and `postgres` as direct-install focused plugins.
