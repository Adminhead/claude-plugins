# Third-party review: large repos (claude-skills, claude-seo, awesome-gamedev-agent-skills, Anthropic-Cybersecurity-Skills)

## Summary

- **Repos covered (all checked out under `3rd-party/`):** claude-skills (MIT, 67 skills plus 10 commands), claude-seo (MIT, 2 plugins: 26 skills, 19 agents and a mod), awesome-gamedev-agent-skills (Apache-2.0, 75 skills in 10 upstream plugins), Anthropic-Cybersecurity-Skills (Apache-2.0, 818 skills, not an Anthropic project).
- **Rows in the table below:** port 3, merge 10, cross-dep 0, skip 33. The bulk categories add about 940 more skips: claude-skills 25, claude-seo about 33 skills and agents, gamedev 75, cyber about 805.
- **claude-skills: the language skills are not worth porting.** `python-pro`, `golang-pro`, `rust-engineer`, `typescript-pro`, `terraform-engineer` and `kubernetes-specialist` are generic "persona plus MUST DO list" skills. They teach things the model already knows, and some guidance is stale: black and Poetry instead of ruff and uv, Next.js 14 caching, "pod security policies", `terraform refresh`. The archived `coding-*`, `infra`, `deploy` and `db` skills are tighter, newer and more specific in every overlap, so the archive wins. Only `the-fool` (idea and decision critique) is worth porting. `feature-forge` contributes one reference file (EARS syntax), merged into planning.
- **claude-seo: skip it as a dependency.** It is a mega-plugin (26 skills, 19 agents) that needs a Python venv and Playwright Chromium. Install it directly from upstream only for SEO projects. `seo-cockpit` is a good mod reference to cite in the repo-local `mod-authoring` skill, not something to ship.
- **gamedev: no new meta.** Upstream already ships focused bundles (`router` plus one engine). Install those directly when doing game work.
- **cyber:** of 818 skills, port 2 focused defensive skills: `dependency-vetting` (npm and PyPI malware, typosquats, dependency confusion) and `mcp-server-audit`. Fold 6 into archived skills as references (SBOM, IaC scanning, GitHub Actions, Docker, Kubernetes PSS, security headers). Skip everything else. About 112 skills have offensive names and 58 sit in red-team or pentest subdomains. All of those are skipped.

## Open questions

1. Are Django, NestJS or Next.js in use? If so, write a fresh focused skill in the archive's style (or take a vendor skill, for example Vercel's for Next.js). Don't port the claude-skills versions.
2. Which meta takes `the-fool`: none (install directly) or the existing `programming-meta` (the repo has `plugins/programming-meta/`, which the brief doesn't mention)?
3. Should `mcp-server-audit` stand alone, or should the archived `mcp/review` skill be revived with it merged in?
4. Is the CLAUDE.md rule "the engine refuses a plugin that registers the same event twice" about registrations across modules? seo-cockpit's single module calls `on('tool.call', ...)` three times and `on('command.run', ...)` four times, each with a different matcher. Check against `claude-code.d.ts` before the mod-authoring skill cites seo-cockpit as an example.
5. Is game dev, SEO or a homelab hardening stack recurring enough for a dedicated meta? The default here is no: direct upstream installs for the first two, and nothing ported for the third.
