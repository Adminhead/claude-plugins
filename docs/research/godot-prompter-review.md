# GodotPrompter review for design-godot.md

Date: 2026-10-17. Reviewed `3rd-party/godot-prompter` = https://github.com/jame581/GodotPrompter @ `bd9d180` (2026-10-14, release v1.15.1). License MIT: `Copyright (c) 2026 GodotPrompter Contributors`, confirmed with `gh`. 845 stars, 52 forks, created 2026-04-03. Overview: `docs/3rd-party/godot-prompter/README.md`. Catalog: `docs/3rd-party/godot-prompter/catalog.md`.

Correction to design 2.2a: the plugin ships **56 skills**, not about 64. The catalog's 66 adds 8 validator fixtures and 2 maintainer skills. It also ships 9 agents and 1 SessionStart hook. All 56 SKILL.md files were read in full and their 202 references skimmed. The testing, debugging, save, FSM and physics references were read closely. Doubtful claims were checked against the Godot 4.7 docs (docs.godotengine.org stable, Context7 `godotengine_en_4_7`) and the 4.6 to 4.7 migration page. Addon versions were checked with `gh`.

## Verdict in brief

- **Tally of the 56 skills:** 43 merge, 7 new, 6 skip. Agents and hooks are skipped.
- **Strongest asset: the version callouts.** Every "Changed in 4.5/4.6/4.7" block that was checked matches the 4.7 docs, and the blocks cite GH PRs. Use them to seed `godot/references/version-notes.md`. They are better than awesome-gamedev-agent-skills on the 4.5 to 4.7 changes.
- **Errors are in older generic content** that the v1.15.1 audit skipped:
  - Godot 3 import flags.
  - `print_debug`.
  - Invented gdUnit4 runners.
  - CanvasGroup "batching" and `OS.gc()`.
  - A `headless` feature tag.
  - `add_control_to_dock`, which is deprecated in 4.7.
  - The Camera2D shake that `ignore_rotation` silences.
  - 4.3 pins in the `.csproj` and CI samples.
- **Never paste.** Rewrite from the content and verify each pitfall row.
- **Take GDScript only.** Every example comes paired with C#, which doubles the length. The C# halves are the least reliable part. C# idioms go to `godot-csharp`.
- **No cross-dependency.** Design 2.2a's call stands: GodotPrompter is a merge source. A cross-dep would add 56 descriptions plus a hook that injects a card into every session and edits CLAUDE.md.
- **`godot-testing` is weaker than the design assumed.** Take only the GUT versus gdUnit4 table, the layout and the naming rules.
- **Best sources found:**
  - State machines, event bus, components and DI wiring.
  - Physics interpolation, Jolt and ragdolls.
  - Localization, navigation, mobile export, the C# 4.7 break list, and Steam release planning.

## Stale or wrong API to fix on port (top items)

Each group section above has the full list. Fact-checked against the 4.7 docs:

1. `godot-debugging`: `print_debug()` "not visible in release". It prints in every build and adds the caller frame.
2. `godot-testing`: `double(X)` used as an instance (needs `.new()`); a GUT `stub` on a property (GUT stubs methods only); invented gdUnit4 runners (use `addons/gdUnit4/runtest.sh -a <dir>`); the C# `: GdUnitTestSuite` base (gdUnit4Net uses `[TestSuite]`).
3. `assets-pipeline`: Godot 3 "Flags > Filter/Repeat" import options (now CanvasItem `texture_filter`/`texture_repeat`); compress default is Lossless, not VRAM; suffix is `-occ`/`-occonly`, not `-occluder`; no mention of `.uid` sidecars.
4. `godot-optimization`: CanvasGroup "batches into one draw call" is wrong (it renders through a backbuffer); `OS.gc()` doesn't exist; garbage-collector advice doesn't apply to refcounted GDScript.
5. `camera-system`: a Camera2D shake that sets `rotation` does nothing while `ignore_rotation` stays at its default `true`. `input-handling`: "`is_action_just_pressed` misses inputs in `_physics_process`" is stale for 4.x.
6. `addon-development`: `add_control_to_dock` is deprecated in 4.7 (use `add_dock(EditorDock)`). "`@tool` scripts are excluded from exports" is false. `#if TOOLS` around a runtime C# class strips it from exports; the same bug is in `godot-debugging`'s reference.
7. `export-pipeline`: web threads are the preset's Thread Support option, not `rendering/threads/thread_model`. "Linux/X11" is 3.x naming. `dedicated-server`: no `headless` feature tag exists. `multiplayer-sync`: `delta_interval` 0 means every network frame, not "disabled".
8. `ai-navigation`: 2D `path_desired_distance` defaults to 20, not 1. `scene-organization`: collision shapes under a plain `Node` container break. `resource-pattern`: no `make_unique()` method exists.
9. `csharp-signals`: `Action<string> +=` on a generated `[Signal]` event doesn't compile. `godot-project-setup`, `csharp-godot` and CI: `Godot.NET.Sdk/4.3.0` and `GODOT_VERSION 4.3` pins; `.import/` in `.gitignore`; the false "namespace must match" rule; `--check-only` used without `--script`.
10. `dialogue-manager`: written for v3.10.4. v4 (2026-08) is current: cues replaced titles, and the syntax changed.
11. Unverified, recheck before porting: `EnableGodotDotNetPreview` (GH-118001); "Android C# export needs .NET 9+"; 4.7 `type_exists()` deprecation; the 4.7 `JSON.stringify` empty-dict change; the C# `Expression` base-instance claim.
